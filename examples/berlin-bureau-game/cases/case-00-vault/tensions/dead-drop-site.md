## Tension

Two couriers filed different sites for the same handoff. One of them is wrong.

**Side A — site-7** (SPARROW, [[fr-t01-sparrow-site7]], B2, 1971-03-02):

SPARROW read the load signal with a clear line of sight and confirmed the site-7 mark against the
network signal key. Usually-reliable source, probably-true credibility.

**Side B — site-4** (WREN, [[fr-t02-wren-site4]], D4, 1971-03-02):

WREN read a chalk mark as the site-4 indicator — but from across the canal, in failing light, as an
unestablished courier still learning the signal key. Not a plant; an honest report that may simply
be mistaken. The low D4 grade reflects exactly that uncertainty.

**Why this is factual, not interpretive:** the walk-in will service one physical site. Both cannot
be right. The kind is `factual`.

**Temperature: 2.** Unlike a sacred tension, this one is expected to resolve — an independent
source can settle which reading was correct.

**Stakes: DECISION.** The Bureau services one site tonight; the tension must resolve before the
courier is dispatched.

## Bridge

Resolution path: find a source **independent of both SPARROW and WREN** to corroborate one reading.
[[fr-t03-sigint-site7]] (A2, signals intercept + static-post observation) does exactly this — it is
tied to neither courier and independently places the run at site-7. That is a second independent
source for Side A, which clears the verification gate (`working → evergreen`). WREN's D4 site-4
reading is not credited but is kept on file, not discarded. Tension resolves toward **site-7**.
