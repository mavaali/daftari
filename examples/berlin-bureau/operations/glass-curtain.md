## Summary

GLASS CURTAIN is the Bureau's border-crossing surveillance and counter-surveillance network operating
along the sector boundary in divided Berlin. The operation maintains a set of surveilled transit
corridors used to move assets, couriers, and materials between sectors.

Case officer: CARTOGRAPHER — responsible for route selection, counter-surveillance schedules, and
asset coordination. NIGHTINGALE provides periodic observation on Directorate activity near crossing
points under this operation.

The network's integrity is conditionally at risk:
- If defector AMBER is a genuine source, AMBER SIGNAL will route the exfiltration through a GLASS CURTAIN corridor.
- If AMBER is a Directorate dangle (see [[amber-genuine-vs-dangle]]), any activated corridor is burned.
- If WEATHERVANE is confirmed as a Directorate double, all active crossing schedules are compromised.

Current status: active, held pending resolution of the AMBER tension.
